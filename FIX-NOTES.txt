JerseyHubGh click-handler fix

The previous main.js called initCart() and initWishlist(), but neither function existed. That caused a JavaScript ReferenceError during page initialization, preventing product click handlers from being registered. The script now renders the cart and wishlist pages only when their containers exist, then registers the product handlers.

For best results, run the site through its Node server rather than opening HTML files directly:
1. Open a terminal in the folder containing package.json.
2. Run npm install.
3. Run npm start.
4. Open http://localhost:3000 and hard-refresh with Ctrl+F5.
